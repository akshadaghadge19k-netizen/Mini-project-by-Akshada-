## Problem Statement

Design and implement a console-based playlist system in C++ using singly linked list, circular linked list, and doubly linked list. Each song represents a node in the list. The system should support insertion of songs, deletion of songs, searching for a specific song by name, displaying the complete playlist, and finding the middle-position song using all three types of linked lists.

## Objectives

- To understand the concept of linked lists in C++.

- To insert and delete songs from a playlist.

- To search for a particular song by its name.

- To display all songs in the playlist.

- To find the middle-position song using singly, circular, and doubly linked lists.

- To understand the differences between the three linked-list types.

## Conclusion
Tune stream - song organiser was successfully implemented in C++ using singly, circular, and doubly linked lists. The program performs insertion, deletion, searching, and displaying of songs. It also finds the middle-position song in each linked list. This assignment helps us understand linked-list operations and how different types of linked lists are used to store and manage data dynamically.
